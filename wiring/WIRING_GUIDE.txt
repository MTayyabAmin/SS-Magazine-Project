SECTION 0C: ESP32-CAM + FTDI — Kab lagana, kab hataana
=============================================================================

ESP32-CAM par USB port NAHI hota — is liye flash ke liye FTDI chahiye.

FTDI sirf PROGRAMMING (flash) ke waqt lagta hai:

  FTDI USB          ESP32-CAM
  +--------+        +------------------+
  |    5V  +--------+ 5V               |
  |   GND  +--------+ GND              |
  |    TX  +--------+ U0R (RX)         |   ← FTDI TX → CAM RX
  |    RX  +--------+ U0T (TX)         |   ← FTDI RX → CAM TX
  +--------+        | GPIO 0 --- GND   |   ← flash mode (sirf upload ke waqt)

*** FLASH KE BAAD FTDI HATA DO ***

  Step 1 — Flash karte waqt:
    • FTDI se ESP32-CAM ko laptop se connect karo
    • GPIO 0 ko GND se jodo (BOOT mode)
    • EN/Reset dabao
    • Arduino IDE se camera_stream.ino upload karo

  Step 2 — Flash complete hone ke baad:
    • GPIO 0 aur GND ke beech ka wire HATA do
    • FTDI USB cable HATA do (poora FTDI alag rakho)
    • ESP32-CAM ko alag 5V power do (FTDI ki 5V se chal sakta hai testing ke
      liye, lekin robot par stable 5V supply use karo)
    • ESP32-CAM khud router se connect hogi aur video stream degi

  Runtime par ESP32-CAM completely STANDALONE hai:
    • FTDI connected NAHI rehna chahiye
    • ESP32 DevKit se koi wire NAHI
    • Sirf: 5V power + WiFi → router → laptop stream

Summary:
  | Device        | Laptop se kaise?        | Runtime par kya connected?      |
  |---------------|-------------------------|----------------------------------|
  | ESP32 DevKit  | Micro-USB (built-in)    | Battery + sensors + motors       |
  | ESP32-CAM     | FTDI (flash ONLY)       | Sirf 5V power — FTDI hata do     |

SECTION 4: HC-SR04 x2 — POWER, DIVIDER, WIRING (READ CAREFULLY)
=============================================================================

*** ESP32 GPIO 3.3V hai — lekin HC-SR04 ko 3.3V se power NAHI dena (ideal) ***

KYUN?
  • ESP32 ke 3.3V pin se TRIG signal bhejna THEEK hai (logic input)
  • HC-SR04 ka VCC (power) 5V maangta hai — 3.3V par range kam / unreliable
  • ECHO pin SENSOR se 5V pulse OUTPUT karti hai → ESP32 GPIO ko 3.3V chahiye
    Is liye divider sirf ECHO par — VCC par nahi!

VCC kahan se?
  → L298N ki 5V output (4700uF cap ke baad) — dono HC-SR04 ka VCC yahi

GND?
  → Common GND (ESP32 + L298N + dono sensors)

─────────────────────────────────────────────────────────────────────────────
SENSOR #1 — FRONT (samne, cruise wall stop)
─────────────────────────────────────────────────────────────────────────────
  L298N 5V ──────── HC-SR04 #1 VCC
  GND    ──────── HC-SR04 #1 GND
  GPIO18 ──────── TRIG
  GPIO19 ──────── ECHO (divider ke through — neeche dekho)

─────────────────────────────────────────────────────────────────────────────
SENSOR #2 — LEFT (90° left mount, T-junction left path)
─────────────────────────────────────────────────────────────────────────────
  L298N 5V ──────── HC-SR04 #2 VCC
  GND    ──────── HC-SR04 #2 GND
  GPIO 5 (D5)  ──────── TRIG
  GPIO15 (D15) ──────── ECHO (divider ke through)

  (Agar RIGHT mount chahiye LEFT ki jagah: GPIO16 TRIG, GPIO4 ECHO)

─────────────────────────────────────────────────────────────────────────────
ECHO VOLTAGE DIVIDER (har sensor par — sirf ECHO line par!)
─────────────────────────────────────────────────────────────────────────────

  HC-SR04 ECHO (5V) ──[ 1kΩ ]──┬── GPIO (19 / 17 / 4)
                               │
                             [ 2kΩ ]
                               │
                              GND

  5V × 2k/(1k+2k) ≈ 3.3V → ESP32 safe

  Agar tumhara module "3.3V compatible" likha ho AUR ECHO 3.3V measure ho
  multimeter se → divider optional. Standard blue HC-SR04 par divider lagao.

  TRIG par divider NAHI — ESP32 3.3V TRIG ko sensor accept karta hai.

─────────────────────────────────────────────────────────────────────────────
2 SENSORS — tum kaun se wire karo?
─────────────────────────────────────────────────────────────────────────────

  Setup A (recommended):  FRONT + LEFT
    • Aage wall detect + T par left seedha
    • Right path = robot rotate (servo NAHI)

  Setup B:              FRONT + RIGHT
    • Same, mirror — right seedha, left rotate se

  Setup C:              LEFT + RIGHT (dono side)
    • T-junction dono taraf seedha scan
    • Cruise ke liye FRONT zaroori — is setup mein samne wall
      detect kamzor — Setup A behtar

Mounting:
  • FRONT: robot ke samne, zameen se ~15cm upar
  • LEFT:  robot ke left side, 90° left point kare
  • Dono VCC 5V parallel L298N se (thick wire)

SECTION 10: COMMON MISTAKES
=============================================================================
1. MPU6050 not found → SDA/SCL swap? 3.3V power? AD0 grounded?
2. Motors not spinning → ENA/ENB jumpers removed? MIN_PWM too low?
3. ESP32-CAM no stream → weak 5V, wrong WiFi creds, GPIO0 still grounded?
4. Laptop can't reach ESP → sab same router par? firewall UDP 4210/4211?
5. Ultrasonic always 0 → ECHO voltage divider lagao, TRIG/ECHO swap check karo.
6. WiFi sensing false positives → pehle empty room baseline lo, phir human test.
